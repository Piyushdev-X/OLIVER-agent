Reading the numbers

claim vs evidence

Two columns on purpose

"Harness claim" is what OLIVER reported; "Hidden tests" is an independent check run after the harness stops.

recoveries

Failures that were fixed

A recovery is a failed verification that the loop repaired within the same run, with the evidence recorded.

scope

Mechanics, not model quality

Scripted trajectories prove the machinery. Run the eval with a real OLIVER_MODEL for model scores.
