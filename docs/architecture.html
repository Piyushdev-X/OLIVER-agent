System architecture · v0.1

OLIVER: a planner–executor coding harness

OLIVER wraps one standardized foundation model and turns it into a careful software engineer: it reads an issue, finds the relevant code, makes a minimal change, and proves the change with tests before it calls the task done.

Python 3.10+ Procedural only Model alias: OLIVER ✓ Constraint check passing

Design principles

Correctness first

Baseline tests run before any edit, so only new failures count. Every edit is syntax-checked and rolled back if it breaks the file.

Evidence over claims

The harness, not the model, decides when a task is done. Each run ships a patch, the test results before and after, and the full trajectory.

Efficiency matters

A ranked repo map instead of whole files, windowed reads, masked old tool output, and hard budgets on steps, tokens and wall time.

System architecture

Core modules

Orchestration Engine

orchestrator.py · foundation_model.py · prompts.py

  • run_agent_loop(task, repo_path) drives a dict of phase functions.
  • All model calls go to the OLIVER alias through LiteLLM, with retries and a text-protocol fallback.
  • Budget guards on steps, tokens and wall time; the harness decides completion.

Context Manager

context_manager.py

  • Indexes the repository and extracts symbols with tree-sitter (ast fallback).
  • Ranks files against the issue into a compact repo map.
  • Keeps a running memory list and compresses old turns without splitting tool calls from results.

Tool & Verification Pipeline

tools.py · verification.py

  • read_file, write_file, search_repo, edit_file, run_command, run_tests, finish.
  • Arguments validated with pydantic validate_call; paths confined to the repository.
  • Baseline and final test runs are diffed so only new failures count.

Recovery System

recovery.py

  • Classifies failures: syntax, import, test, timeout, tool misuse, model API, loop.
  • Trims tracebacks into a short, specific recovery prompt.
  • Rolls back to the last good checkpoint and replans when a failure repeats.
